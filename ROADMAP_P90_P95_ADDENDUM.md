# Roadmap addendum — P90 a P95

Fluxo: P89 fechamento da governança → P90 solicitação de uso controlado → P91 observação factual → P92 avaliação explícita → P93 disposição → P94 admissão operacional controlada → P95 fechamento.

P90 registra a intenção de uso dentro do escopo autorizado. P91 registra observações. P92 avalia explicitamente. P93 define disposição administrativa. P94 admite somente RETAIN para ambiente controlado. P95 fecha o ciclo factual.

Invariantes: imutabilidade, determinismo, fail-closed, proveniência preservada, nenhuma inferência automática de lucro/causalidade, nenhuma mutação de estratégia/score/risco e REAL sempre bloqueado.
